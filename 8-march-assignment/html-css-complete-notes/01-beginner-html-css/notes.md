# 01 Beginner HTML + CSS

## Definition
Beginner HTML/CSS covers document structure, common tags, and basic styling.

## Key Points
- HTML skeleton: `<!DOCTYPE html>`, `html`, `head`, `body`
- Content tags: headings, paragraph, list, link, image
- CSS basics: selectors, properties, values

## Example Code
```html
<!DOCTYPE html>
<html>
<head>
  <title>Beginner Demo</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>My First Page</h1>
  <p>Learning HTML and CSS.</p>
</body>
</html>
```

```css
body {
  font-family: Georgia, serif;
  background: #f5f7fb;
}
```
